# Krish Sharma — Developer Portfolio

A personal developer portfolio built to showcase my projects, technical skills, development experience, and work across Full Stack Web Development, Data Science, and AI/ML.

## About

This portfolio represents my work and learning journey as a developer. It includes selected projects, technical skills, and links to my professional profiles and deployed applications.

The portfolio is designed with a responsive interface and interactive animations while keeping the overall experience simple and professional.

## Tech Stack

- React.js — Component-based frontend development
- Vite — Fast development and production build tooling
- Tailwind CSS — Responsive UI styling
- Framer Motion — Animations and interactive transitions
- JavaScript — Application logic and functionality
- HTML5 — Page structure
- CSS3 — Styling and responsive layouts

## Features

- Responsive design for desktop, tablet, and mobile
- Project showcase with project links
- Technical skills section
- About and developer profile sections
- Smooth page transitions and animations
- Interactive UI components
- Links to GitHub, LinkedIn, and deployed projects
